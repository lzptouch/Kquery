## 零、结论速览

### 0.1 一句话结论

> **这是一个"工程习惯扎实、但工具化缺位"的代码库。** 领域设计（统一信封、结构化日志、PII 脱敏、三端探针、fail-fast 启动校验、Fail-Open 缓存）明显高于同期平均水平，文档与注释密度罕见地高；但**三条最要命的底线被漏掉了：异步纪律（阻塞调用直落事件循环）、模块级无界内存表、优雅停机**，而这些恰恰是 02/03 号文档里标红的三条。根因不是作者不懂，而是 **ruff 只选了 `E/F/W` 三族规则 + CI 无 grep 纪律门禁**，导致所有能自动发现的违规都失去了拦截机制。

### 2.1 §六 异步代码纪律（四条铁律）

> **这是本次审计最严重的发现。**

**关键事实**：`app/` 全仓仅 **8 个 `async def`**（`main.py` 6 个 + `api/knowledge.py:39` + `api/ingest.py:47`），**`services/**` 里一个都没有**；`asyncio.to_thread` / `run_in_executor` / `ProcessPoolExecutor` 命中 **0 次**。

这个事实有两面性：服务层全部是同步代码（由 Starlette 线程池承载，本身不阻塞事件循环），**但两个 `async def` 端点把整条同步重链路直接拉回了事件循环**。

|---|---|---|---|

## 四、代码修改计划

### 4.0 执行原则（依 03 号 §一）

> **1. 新代码从严、存量豁免。** 风格层面的存量清理（21.6% 注解补齐、88 行 import 排序）是纯 churn，会污染 git blame。**ruff 新规则先以 `warn` 或 `# noqa` 白名单方式接入，只拦新增与变更行**，存量分批随功能改动顺带清理。
> **2. 每批次独立可交付、可验收、可回滚。**
> **3. 先让机器替人查，再改代码。** 批次 0 完成前，后续批次的所有整改都缺少"是否引入新违规"的验证手段。
> **4. 有意的架构取舍要记录，不要当违规改掉。** `--workers 1`、`propagate` 架构差异、`SqlSearchTool` 内联 SQL、starlette 线程池承载同步端点——这些都是有理由的决策，需写入 `doc/analysis/架构取舍.md` 并在代码里补注释。

**目标**：让 `ApiError` 真正成为统一基类，接上 12 个孤儿错误码，建立错误分类计数，消除静默异常与真相源 Fail-Open。

**① 异常基类化**

新建 `app/core/errors.py`（**不要放进 `envelope.py`**——`envelope.py` 是 HTTP 契约，异常基类是领域层，`envelope.py` 应依赖它）：

```python
"""领域异常体系：一个基类 + 按模块划分的少量子类。

设计取舍：调用方是否需要区别处理 —— 需要才建子类。子类过多会导致 except 不完。
不与 HTTP 耦合：状态码由 envelope.py 的映射表提供，而非写在异常类上（02 号 §5.2 方案 A）。
"""
from __future__ import annotations


class AppError(Exception):
    """项目所有业务异常的基类。"""

    kind = "internal"          # 供指标分类（errors_total{kind}）
    err_code_name = "INTERNAL_ERROR"

    def __init__(self, message: str, *, cause: BaseException | None = None) -> None:
        super().__init__(message)
        self.message = message
        self.cause = cause


class DependencyUnavailable(AppError):
    """外部依赖不可用（Milvus / Redis / dashscope / 图存储）。Fail-Hard。"""
    kind = "dependency"


class RetrievalFailed(AppError):
    """全部检索路失败。"""
    kind = "retrieval"


class ParseFailed(AppError):
    """文档解析失败（含加密文档、扫描件 OCR 全失败）。"""
    kind = "parse"


class ToolExecutionFailed(AppError):
    """Agent 工具执行失败。"""
    kind = "tool"


class CacheDegraded(AppError):
    """缓存不可用（**内部使用，API 层应转为降级标记而非异常**）。"""
    kind = "cache"
```
