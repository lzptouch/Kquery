# 图文混排语料（开源素材）

本文件把**真实开源图片**与说明文字交错排布，用于验证「图文绑定 → 答案引用时回显原图」这条链路（M4 / M6）。

图片均来自 BSD / MIT 许可的开源项目，来源与许可见 `SOURCES.md`。

## 图：astronaut
![astronaut](images/astronaut.png)

【主体】一名女宇航员的官方肖像照。
【属性】她穿着橙色 NASA 宇航服，宇航头盔挂在胸前，肩臂上有航天员臂章与任务臂章，短发向后梳起，面带微笑直视镜头。
【场景】室内摄影棚背景：身后左侧是一面美国国旗，右侧立着一架航天飞机模型，地面是浅灰色幕布。
【图中文字】画面中没有可读文字，只有两枚 NASA 臂章上的徽标与细小字样。
