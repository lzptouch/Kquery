## 一、分层策略与边界

| 层 | 位置 | 定位 | 不应覆盖什么 |
|---|---|---|---|
| unit | `tests/unit/` | 纯逻辑：算法 / 状态机 / 解析器 / 存储适配，Mock 一切外部 | 不打 HTTP 端点、不依赖 lifespan 装配 |
| integration | `tests/integration/` | TestClient 全链路：端点 + 真实管线（Mock 模型）+ 真实向量库（平台回退见 §三） | 不验真实 LLM 行为、不验浏览器 |
| e2e | `tests/e2e/` | 对运行中服务的 API 端到端 | 不做 UI 断言 |
| e2e_ui | `tests/e2e_ui/` | 浏览器级 UI 链路（独立 conftest） | 不做单元级逻辑断言 |
| contract | `tests/contract/` | 从 `app.openapi()` 枚举端点，钉跨端点结构约束（路由清单分类 / 错误码值域 / 404 分层 / 405 / trace 透传 / 信封声明） | 不验业务语义（由 integration 覆盖） |
| security | `tests/security/` | 数据隔离矩阵：自报身份无效、按 id 越权一律 404 且无副作用 | 不验认证/授权协议（已下线） |
| 前端 vitest | `frontend/tests/` | 组件 / 工具函数：渲染与交互 | 不调真实后端 |
| 脚本级 | `scripts/` | 对部署实例的冒烟 / 扫描 / 浏览器验证 / 压测 | 不进 CI（现状，见 §六缺口） |
| 评测级 | `scripts/eval/` | **检索质量**（金标 / 切块实验 / 重建 / Agent 过程 / 图文对抗题） | 进 CI（`retrieval-eval` job）：门禁只对「相对基线劣化 >2pp」生效 |
