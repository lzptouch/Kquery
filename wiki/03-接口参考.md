# 03 接口参考

## 1. 基本约定

- 基地址：后端默认 `http://127.0.0.1:8100`；容器化部署时前端由 nginx 反代到同源 `/`，浏览器侧无需跨域。
- 全量契约以 `GET /openapi.json` 为准（服务启动后可直接打开）；本文只做分组导航与关键语义说明。
- 请求/响应为 JSON；流式问答为 `text/event-stream`。
- 响应信封统一：成功返回业务对象，失败返回 `{code, message, trace_id}`，`code` 为稳定错误码字符串（见 `backend/app/core/envelope.py`）。

### 关于认证

本仓库**已下线认证与授权**（2026-11-12）：没有登录、没有 ACL、没有角色门禁。所有请求身份固定为 `tenant_id=default`、`user_id=local`，`core/identity.py` 里写明这是数据模型的一部分而不是权限功能。

> **部署到公网前必须自行加一层保护**（反向代理 Basic Auth、内网限制或网关鉴权）。`/admin/*` 的运维端点在当前形态下是开放的。

## 3. 典型调用

### 3.1 入库并等待完成

```bash
# 上传（返回 task_id）
curl -s -F "file=@manual.pdf" http://127.0.0.1:8100/knowledge/upload

# 轮询任务
curl -s http://127.0.0.1:8100/knowledge/tasks/<task_id>
```

### 3.2 同步问答

```bash
curl -s -X POST http://127.0.0.1:8100/ask \
  -H 'Content-Type: application/json' \
  -d '{"question":"退换货时效是多久？","top_k":5}'
```

### 3.3 流式问答

```bash
curl -N -X POST http://127.0.0.1:8100/ask/stream \
  -H 'Content-Type: application/json' \
  -d '{"question":"退换货时效是多久？"}'
```

响应按 `evidence` → `answer` → `done` 顺序到达；客户端应容忍未知事件与乱序之外的重复事件。

## 4. 错误处理

- 错误码是**字符串常量**（不是数字），定义集中在 `backend/app/core/envelope.py` 的 `ErrCode`，新增错误码必须同时更新前端映射与契约测试。
- 响应带 `trace_id`，用它查 `/admin/metrics/top-queries` 或日志定位。
- 常见语义：`E_*_NOT_FOUND` 资源不存在、`E_*_INVALID` 参数非法、`E_*_UNAVAILABLE` 依赖不可用、`E_*_TIMEOUT` 超时。
