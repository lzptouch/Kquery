# 知识图谱技术概述

## 基本概念

知识图谱（Knowledge Graph）以"实体-关系-实体"三元组形式组织和存储知识。它以结构化的方式描述现实世界中的概念、实体及其相互关系。

**核心要素**：实体（Entity）、关系（Relation）、属性（Property）、三元组（Triple）。

相比关系数据库，知识图谱具有图结构、灵活模式、高效多跳关联查询等优势。知识图谱可以动态扩展模式，而关系数据库需要预先定义严格的表结构。

## 构建流程

### 信息抽取
从非结构化文本中抽取结构化知识：NER 命名实体识别、关系抽取（RE）、属性抽取、共指消解。

### 知识融合
将来自不同数据源的知识进行整合：实体对齐、冲突解决、实体链接、知识合并。

### 知识存储
- **Neo4j**：最流行的图数据库，支持 Cypher 查询语言
- **Amazon Neptune**：AWS 的托管图数据库服务
- **ArangoDB**：多模型数据库
- **JanusGraph**：分布式图数据库

### 知识推理
基于现有知识推导新知识：基于规则推理、基于嵌入推理（TransE、TransR、RotatE）、图算法推理。

## 知识图谱嵌入

将实体和关系映射到低维向量空间：
- **TransE**：关系视为头实体到尾实体的平移
- **TransR**：在关系特定空间中建模
- **RotatE**：在复数空间中建模为旋转变换
- **ConvE**：使用 CNN 进行评分函数计算
- **R-GCN**：图卷积网络在知识图谱上的应用

## Cypher 查询示例

```cypher
// 查询实体关系
MATCH (e:Entity {name: '人工智能'})-[r]->(related)
RETURN e, r, related

// 最短路径
MATCH p = shortestPath(
  (a:Entity {name: '机器学习'})-[*..6]-(b:Entity {name: '深度学习'})
)
RETURN p

// 社区发现
CALL gds.louvain.stream('knowledgeGraph')
YIELD nodeId, communityId
RETURN gds.util.asNode(nodeId).name AS name, communityId
```

## 应用场景

智能搜索引擎、推荐系统、问答系统、风险控制、药物发现等。在 KQuery Pro 项目中，知识图谱是 GraphRAG 引擎的核心组件，为智能问答提供结构化推理能力。
