# Kquery Agent 运行时

## 工具注册表

工具注册表是 Planner 的工具目录来源，也是执行期的分发入口。每个工具有 name 与 description，
模型据此选工具。写类工具必须先经人工审批，未审批时返回结构化错误而不是抛异常。

## 工具健康熔断

连续失败达到阈值（默认 5 次）就把工具摘除，摘除后不再参与业务流量；
半开探测成功累计到阈值（默认 3 次）才重新挂载。

## 预算

Agent 有三个预算维度：token、成本（按价格表折算）、deadline。
判定口径是"剩余额度是否够这一次调用的下界"，不够就提前拒绝，避免执行到一半才发现超限。

## 取消

取消的语义是"不再产生新的模型与工具调用"，而不是掐断正在执行的那一个。
