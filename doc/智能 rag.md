# 智能RAG（Agentic RAG，新一代智能检索增强生成）完整功能
> 传统RAG：固定流水线「一次检索→直接生成」；**智能RAG（Agentic RAG）** 把大模型作为调度Agent，具备**规划、迭代检索、自我校验、工具调用**闭环，同时包含GraphRAG、多模态RAG能力，是2025–2026主流生产级RAG形态

## 一、文档数据预处理&知识库构建能力
1. **多源数据源连接器**：支持本地文档、PDF、Word、Markdown、网页爬虫、OneDrive/SharePoint/对象存储、数据库、API数据一键接入，支持自动增量同步、定时更新知识库，新增文档自动入库，无需全量重建索引。
2. **智能分块（Chunking）**：语义感知分块、父子分块、递归摘要分块（RAPTOR），保留章节/表格/版式逻辑；不是简单按字符切割，保证信息完整性，减少上下文断裂。
3. **实体抽取与知识图谱构建（GraphRAG）**：自动从文档提取实体、事件、关系，构建知识图谱；把孤立文档片段变成实体关联网络，适合跨文档多跳推理（A关联B，B关联C这类链式问题）。
4. **多模态解析**：OCR识别图片、扫描件；解析表格、图表、图纸；提取音视频字幕+画面信息，图文混合检索问答（图纸、截图、PPT均可入库）。
5. **元数据标记**：自动打上文档时间、作者、来源、权限标签，检索时按元数据过滤（只查2026版本文档）。

## 二、查询理解与前置智能处理（Query侧）
1. **用户意图识别**：区分事实问答、对比、总结、计算、代码查询；判断问题**是否需要检索**，通用常识问题直接回答，节省检索开销。
2. **查询改写/扩展**：自动补全同义词、转述模糊提问；生成多个并行检索query，解决用户口语化提问和文档措辞不匹配问题。
3. **复杂问题拆解**：多跳问题自动拆成多个子任务。例：对比两款产品，拆成「A参数检索」「B参数检索」，分步收集证据，再合并答案。
4. **数据源路由**：自动选择知识库，决定调用向量库、图数据库、SQL数据库还是联网搜索，多知识库联合检索。

## 三、高级检索核心能力
1. **混合检索（Hybrid Search）**：**BM25关键词检索 + 向量语义检索**，结果融合重排；精确编号、型号用关键词，概念解释用语义检索，兼顾召回率和准确率。
2. **神经网络重排序（Rerank）**：初次召回Top-K候选片段，用交叉编码器模型二次打分，过滤噪声、优先选择高相关片段。
3. **迭代多轮检索（核心区别于传统RAG）**：
    - 第一轮检索信息不足 → Agent自动改写query，再次检索；
    - 循环「检索→评估证据是否足够→继续检索/停止」，直到信息满足回答需求，也叫多跳检索。
4. **图检索（GraphRAG特有）**：基于实体关系图谱做图遍历，挖掘文档间隐藏关联，适合复杂业务、论文、法律、项目档案类分析。

## 四、答案生成、校验与溯源能力
1. **引用溯源与证据标注**：输出答案附带原文引用片段、文档来源、页码，每一条结论绑定出处，支持点击溯源，方便核验。
2. **自反思、自校验、自我修正（Self-Correction）**：
    - 生成前评估检索证据是否充足；
    - 生成答案后自动检查逻辑冲突、事实矛盾；
    - 发现信息缺失/冲突，自动触发新一轮检索，降低幻觉；信息不足会直接告知「知识库无相关内容，无法回答」，拒绝编造内容。
3. **输出样式定制**：自动输出摘要、报告、对比表格、清单、代码、会议纪要；支持长文档精读总结、多文档合并综述。
4. **多轮对话记忆**：保留对话上下文，后续提问可以承接上文，支持对话压缩，避免上下文窗口溢出。

## 五、工具调用与外部系统集成（Agent能力）
- 内置工具：联网搜索、SQL查询结构化数据库、代码执行、计算器、API调用；
- 工作流编排：检索结果交给外部系统，也可把外部数据库数据拉进检索链路；
- 多智能体协同：拆解任务给多个子Agent，分工检索、校验、撰写、评审，复杂分析场景使用。

## 六、运维、评测、可观测（企业级必备）
1. **全链路日志可观测**：记录用户query、改写内容、检索召回列表、重排分数、最终答案；每一步链路可复盘调试，定位召回差、幻觉来源。
2. **自动化评测**：批量跑测试集，自动计算召回、准确率、幻觉率，用来调优分块、embedding、检索参数。
3. **权限与安全管控**：文档级细粒度权限控制、数据脱敏、敏感词拦截、知识防泄漏、私有数据隔离、拒答机制；支持审计日志，满足合规要求。
4. **监控与告警**：检索延迟、token消耗、异常问答、知识库同步状态监控。

## 七、典型业务应用功能
- 知识库问答、企业内部助手、技术文档答疑；
- 长文档精读：合同、论文、财报、产品手册的提取、对比、风险识别；
- 多模态文档分析：工程图纸、扫描档案、PPT图文问答；
- 数据联合查询：非结构化文档 + 业务数据库联合分析；
- 知识库助手API，嵌入业务系统（客服、OA、开发平台）。

## 传统RAG vs 智能RAG简要对比
| 维度 | 传统Naive RAG | 智能Agentic RAG |
| ---- | ---- | ---- |
| 流程 | 固定单轮：Query→检索→生成 | 闭环循环：规划→检索→评估→迭代→校验→生成 |
| 检索 | 一次性召回，不判断信息够不够 | 自主决策，多轮迭代检索，按需换数据源 |
| 复杂推理 | 弱，难以跨文档多跳问题 | 强，GraphRAG实体关系推理，支持复杂分析 |
| 自我校验 | 基本没有 | 内置反思、证据核验、幻觉自检 |
| 工具 | 仅向量检索 | 可调用SQL、代码、Web搜索、外部API |
