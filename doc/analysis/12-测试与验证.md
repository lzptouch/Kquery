## 〇、摘要

- 后端测试分四层：unit（24 文件）/ integration（27 文件）/ e2e（2 文件）/ e2e_ui（5 文件，含独立 `conftest.py`），共 58 个测试文件；前端 vitest 8 个用例文件（+ `setup.ts`）。用例数见 README 关键数字表。
- 测试基座的关键约定全在 `backend/tests/conftest.py:32-66`：每用例独立临时 `DATA_DIR` + `MODEL_PROVIDER=mock` + `AUTH_ENABLED=false` 走 Header 透传 + admin 头注入（`backend/tests/conftest.py:29`）。
- pytest 强制 120s 超时（`--timeout-method=thread`）：大量用例涉及线程与 SSE 消费，无超时会静默挂住（`backend/pyproject.toml:58-63`）。
- CI 四个 job：lint / test（双 Python 版本矩阵 + 覆盖率上传）/ test-quality（静态护栏）/ frontend-build（typecheck + build + 单测）（`.github/workflows/ci.yml:14-93`）。
- 三条架构约束被测试钉死：OCR 云服务化、已下线功能必须 404、conftest admin 头注入（§七）。
- 明确缺口：**没有检索金标集、没有 Agent 过程评测、阈值无标定入口**（§八）。

## 一、分层策略与边界

| 层 | 位置 | 定位 | 不应覆盖什么 |
|---|---|---|---|
| unit | `backend/tests/unit/` | 纯逻辑：算法 / 状态机 / 解析器 / 存储适配，Mock 一切外部 | 不打 HTTP 端点、不依赖 lifespan 装配 |
| integration | `backend/tests/integration/` | TestClient 全链路：端点 + 真实管线（Mock 模型）+ 真实向量库（平台回退见 §三） | 不验真实 LLM 行为、不验浏览器 |
| e2e | `backend/tests/e2e/` | 对运行中服务的 API 端到端 | 不做 UI 断言 |
| e2e_ui | `backend/tests/e2e_ui/` | 浏览器级 UI 链路（独立 conftest） | 不做单元级逻辑断言 |
| 前端 vitest | `frontend/tests/` | 组件 / 工具函数：渲染与交互 | 不调真实后端 |
| 脚本级 | `scripts/` | 对部署实例的冒烟 / 扫描 / 浏览器验证 / 压测 | 不进 CI（现状，见 §六缺口） |

## 三、conftest.py 关键约定

`backend/tests/conftest.py` 是全测试体系的基座，每条约定都有注释说明原因：

| 约定 | 内容 | 代码位置 |
|---|---|---|
| `ADMIN_HEADERS` 注入 | 功能测试默认以 admin 身份访问（`X-User-Id/X-Tenant-Id/X-Roles`）；权限边界类用例显式传 headers 覆盖 | `backend/tests/conftest.py:27-29`、`:62` |
| 每用例独立临时 `DATA_DIR` | `TemporaryDirectory` + 环境变量注入，用完清理全部注入键 | `backend/tests/conftest.py:34-35`、`:64-66` |
| `MODEL_PROVIDER=mock` | 无需千问凭据跑通全链路 | `backend/tests/conftest.py:36` |
| `AUTH_ENABLED=false` | 测试走 Header 透传（HeaderAuthProvider），用例不受凭证约束；生产默认开启 | `backend/tests/conftest.py:37-38` |
| `RETRIEVAL_CONFIG_APPLY_DELAY_S=0` | 配置变更立即生效，不等 300s | `backend/tests/conftest.py:39` |
| Milvus/FAISS 平台回退 | win32 → faiss（milvus-lite 的 gRPC AllocTimestamp 未实现且锁文件 teardown 被占用），其它平台 → milvus-lite 文件库（真实 Milvus API）；`VECTOR_STORE` 可显式覆盖 | `backend/tests/conftest.py:40-48` |
| CRAG 阈值贴合 Mock 评分分布 | 测试用 0.3 / 0.1；生产默认须按真实评测集标定 | `backend/tests/conftest.py:49-51` |
| ASR 关闭 | `SPEECH_ASR_PROVIDER=none`：① `.env` 里的真实凭据会被读进来反转「语音不可用」断言；② 测试绝不真调云 ASR；需要转写行为的用例自己 monkeypatch | `backend/tests/conftest.py:52-56` |
| `upload_sample` 辅助 | 上传内置 Markdown 样例（产品手册）并断言 200 | `backend/tests/conftest.py:69-75` |
| 设置缓存清理 | 前后各 `get_settings.cache_clear()`，防配置串用例 | `backend/tests/conftest.py:57-64` |

## 七、守卫测试

架构约束不靠约定而靠测试钉死：

| 约束 | 守卫 | 机制 |
|---|---|---|
| OCR 一律云服务 API | `backend/tests/unit/test_ocr_cloud_only.py` | 非法 provider（local / onnx / paddleocr 等）在启动期与解析期都必须直接报错；白名单见 `parsers/ocr.py:161` |
| 已下线功能必须 404 | `backend/tests/integration/test_removal_regression.py` | 下线端点一旦被人重新挂载，测试立即变红 |
| conftest 必须注入 admin 默认头 | CI `test-quality` job 静态 grep | `grep -q "X-Roles" tests/conftest.py`（`.github/workflows/ci.yml:68-69`）——鉴权改造后没有这行，鉴权测试全红且原因不直观 |
| 禁恒真断言与死代码 | CI `test-quality` job | `! grep -rn "or True" tests/` 等（`.github/workflows/ci.yml:64-67`） |

## 八、覆盖现状与未覆盖面

已有覆盖：主链路（线性 / Agentic / 快问）、检索与重排、解析与切块、护栏（认证 / ACL / 突发限流）、并发分层、图谱与多模态、可观测埋点，均有 unit + integration 双层（§二）。配额、敏感词、审计三组功能的用例已随功能下线移除，其下线边界由 `test_removal_regression.py::TestSecurityFeaturesRemoved` 守住（端点 404 + 统一信封 + OpenAPI 无残留 + 后端图谱仍可用）。

**明确未覆盖（登记）**：

1. **没有检索金标集**：检索质量没有带标准答案的评测集，RRF / 重排参数调整无回归标尺。
2. **没有 Agent 过程评测**：只有熔断率 / 迭代数等运行指标（→ `10-可观测性与成本.md` §二），没有「规划质量 / 工具选择正确性」的过程评估。
3. **阈值无标定入口**：CRAG 阈值、兜底阈值、实体消歧阈值只有配置注释里的标定口径（`core/config.py:87-93`），仓库内没有标定工具与评测集，换评分器 / 换语料时的重新标定是手工过程。
4. 真实模型行为无 CI 覆盖：CI 全 Mock；真实千问路径只能靠人工本地验证。
